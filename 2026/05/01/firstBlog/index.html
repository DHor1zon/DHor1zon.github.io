欢迎来到我的博客！

这个博客在2026.5.1创建，截至2026.6.14已经有一个多月了，一直是一篇Hello World挂在这，也不是个事，所以就在这写一篇博客当作开场吧~

不知道写什么，就分享一些我喜欢的工具、网站之类的吧。

账号安全类

这是最重要的一个

登陆时安全

现在的很多互联网厂商要求在登陆过程中使用两步验证来确保登陆过程安全可靠，常见的两步验证器有：

  • Microsoft Authenticator
    （兼顾密码管理与两步验证功能，和微软产品配合很好）

  • Google Authenticator
    （我没用过，不过和谷歌适配应该会很好，不过正常获取不了）

  • 1Password / Bitwarden
    （同样的兼具密码管理与两步验证功能的软件，只是官网有时不太好访问）

！注意，千万不要去应用商店里下载一些打擦边球的软件！

密码管理

好用且安全的密码管理工具应该是：

  • 非对称加密的
  • 功能完善的

因此，可以尝试这些软件：

  • 1Password / Bitwarden
    （风评极好的软件，安全与使用体验上非常舒服）

  • 手机自带的密码保险箱之类的软件
    *（和系统兼容很强。你也不想微信支付的时候跳出来保存密码的界面吧）

！不很推荐edge的密码存储功能，在内存里明文存储不是人类能想出来的！

网页浏览

互联网的必备技能

浏览器

  • windows无脑 Edge / Google Chrome / 火狐

  • 移动端无脑 Via / Edge / 火狐

加速工具

！只讨论合法合规的加速方式！

  • Watt Toolkit
    （好用的加速工具，上到网盘服务，下到Github都能加速，神中神）

  • UsbEAm Hosts Editor / Steamcommunity 302
    （前者范围广，后者专精Steam和Github，修改Hosts以加速）

  • 各种加速器
    （没用过多少，不做评价，本质上是用价格换体验）

各种工具

大佬大佬这个压缩包怎么打开

解压缩工具

  • 7-Zip
    （老牌强者，压缩率极高，唯一的缺点是界面不怎么现代化）

  • Bandizip
    （v6.29无广告，再往后就有了。界面现代化，好看）

  • WinRAR
    （老牌强者，无限续杯，良心）

下载器

  • 文件下载 IDM / FDM / NDM
    （口碑这一块）

  • BT种子下载 qBittorrent / BitComet (比特彗星) / Motrix
    （好用，注意比特彗星可能会捆绑流氓软件）

其他

  • Microsoft 365
    （你肯定听说过Excel、Word和PPT，没错，就是Microsoft365的前身）

  • VS Code
    （轻量高扩展性的编辑器）

网站

  • Github
    (天下谁人不识君)

  • Virus Total
    （在线的恶意程序分析查找网站）

  • LinuxDO
    （友善包容的社区）

其实，这里面有很多国人的开发项目的。总之是在慢慢发展中，未来可期。

哦对了我的Github，此外感谢AI以及微机老师课上教的知识帮助我完成这份MarkDown，谢谢你们qwq
